## 4. กฎเฉพาะแบบฟอร์ม

### ปร.1(ก)

- แถวสรุปเดียวต่อหมวดงาน
- กล่องเงื่อนไข Factor F 4 อัตรา: ค่าจ้างล่วงหน้า / เงินประกันผลงาน / ดอกเบี้ย / VAT — จากตารางที่เลือก
- ตัวอักษรบาทต้องตรงกับยอด
- เนื้อที่อาคาร (ตร.ม.) และราคาเฉลี่ย/ตร.ม. เมื่อมีข้อมูล
- ลายเซ็นผู้จัดทำ/ผู้ตรวจสอบ/ผู้อนุมัติ

### ปร.1

- สรุปหมวดงานก่อนรายละเอียด
- แต่ละแถวแสดงปริมาณ หน่วย ราคาวัสดุ/ค่าแรง และจำนวนเงิน
- แถวที่ยังไม่แยก ก./ข. ต้องมี warning (`unsplit`) — ห้ามเงียบ

### ปร.2(ก) / ปร.2

- ครุภัณฑ์แยกจากงานก่อสร้าง
- VAT มาจาก `FactorFTable.vatPct`; ไม่มีตาราง → `null` + unverified
- ค่าติดตั้งต้องมีเหตุผลและรายละเอียดการสืบราคา; ขาด → `installReasonMissing`
- `totalSat` รวม VAT/ค่าติดตั้งตามที่ทราบ

### ปร.3 / เหตุผล

- เกิดเมื่อมี `project.specialExpenses`
- VAT ของปร.3 ยัง unverified (U1) — ต้องติดป้าย
- แนบท้ายสัญญาบล็อกโครงการที่มีปร.3

### ปร.4

- 3 ส่วน: ค่าก่อสร้าง / ค่าครุภัณฑ์ / ค่าใช้จ่ายพิเศษ
- ตัวอักษรบาท
- จำนวนแผ่นรวม = `5 + p1Pages + (p2 ? 2 : 0) + (p3 ? 1 + p3.reasons.length : 0)`
- ห้ามใช้ `calc.total` เป็นราคากลางในเอกสารราชการ

### ชิ้น 8

- ตาราง Factor F เต็มตามประกาศ
- ไฮไลต์แถวที่เครื่องยนต์ใช้ (`used`)
- ระบุคอลัมน์ที่ใช้จริง (รวม VAT / ไม่รวม VAT / ฝนชุก)
- แสดง A, F, afterFactor และหมายเหตุการปัด

### ชิ้น 9

- ทุกแถวมีที่มา: TPSO (จังหวัด/เดือน/ปี/ราคา ณ เลือก) หรือคลังส่วนตัว (พร้อม note)
- ราคา >12 เดือน → `stale` + รายละเอียด
- ราคาส่วนกลางที่เดือนอ้างอิง ≥ เดือนพิมพ์ → `notYetPublished` + unverified
- ภาคครุภัณฑ์ (`equipmentEvidence`) ต้องอยู่ก่อนภาคค่าติดตั้ง
- ราคาที่ไม่ระบุแหล่ง → `unstated` + warning

## 6. แนบท้ายสัญญา — หน้าพิมพ์

- หน้าแยก `/projects/[id]/docs/contract`
- เจ้าหน้าที่พัสดุกรอกราคาตามคำเสนอของผู้ได้รับคัดเลือก **ช่องเดียว**
- ระบบกระจายอัตราลดเดียวทุกรายการ + เศษเข้ารายการเงินมากที่สุด
- ฐาน = `rep.contractBase` (ตรง ปร.4)
- ป้าย “ไม่ใช่ราคากลาง/ไม่ใช่ราคามาตรฐานของกรมบัญชีกลาง” ทั้งหน้าและ xlsx
- superseded/`rep.warnings` ต้องพิมพ์บนกระดาษจริง
- ลายเซ็นเจ้าหน้าที่พัสดุ/ผู้รับจ้าง/พยาน
- ปร.3 → แสดงข้อความบล็อก ไม่สร้าง lines

## 8. Dynamic year และ superseded

- ใช้ `rulesetBeYear(ruleset)` สำหรับปี พ.ศ. ในชื่อเรื่อง/ชื่อไฟล์/หัวกระดาษ
- `null` → แสดง “ไม่ทราบปี (unverified)” ห้าม fallback 2569
- `rulesetStatus = superseded` → warning + พิมพ์จริง
- `rulesetChecksum`/provenance ต้องแสดงในชีต 00 และท้ายชุด
