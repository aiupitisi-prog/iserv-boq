# หลักเกณฑ์ราคากลางงานก่อสร้าง (ภาครัฐ) — เช็กลิสต์ v2

เวอร์ชัน 2.0 — 19 พ.ย. 2569 · เจ้าของ: `boq-compliance-reviewer` / `boq-calc-engineer`
ใช้ร่วมกับ `boq-money-invariants`, `boq-report-2569`, `boq-ruleset-pipeline`

> ⚠️ **กฎเหล็ก:** ตัวเลขทั้งหมด (ตาราง Factor F, อัตราค่าแรง 30–37%, เงินเผื่อจำเป็น, ดอกเบี้ย, VAT)
> ต้องมาจากเอกสารทางการที่มีผลบังคับและเก็บใน ruleset registry พร้อม `sourceDoc`, `effectiveFrom`, `checksum`
> **ห้าม copy ตัวเลขจากความจำ/สรุป/บล็อก** — ถ้าไม่มีต้นฉบับ ให้ตอบ **“unverified”** และระบุเอกสารที่ต้องเปิด
> ห้ามเดาข้อกฎหมาย

## 1. ลำดับคำนวณ (บังคับ)

1. รายการ: ราคาวัสดุ/ค่าแรงต้นทุนจริง → ปริมาณ × ราคา/หน่วย
2. รวมต่อ **ปร.1** → ต้นทุนโดยตรงของโครงการ (A) — ครุภัณฑ์ไม่เข้าฐาน
3. **Factor F** — ปรับตามเงื่อนไขการจ่ายเงิน:
   - เลือกตารางจาก (advancePct, retentionPct, interestPct, vatPct)
   - หาแถว [B, C] ที่ A อยู่ระหว่าง → `F = D − (D − E) × (A − B) / (C − B)`
   - A เท่ากับขอบ → ใช้ค่าแถวนั้น; นอกตาราง → typed error ห้าม extrapolate
   - ห้ามคำนวณ F จากองค์ประกอบเอง
4. **ปร.1(ก)** — ค่าก่อสร้างรวม × F (แสดง trace)
5. **ปร.2(ก)/ปร.2** — ครุภัณฑ์แยก + VAT + ค่าติดตั้ง
6. **ปร.3/ปร.4** — ค่าใช้จ่ายพิเศษ + สรุปรวม
7. **ค่าแรง fallback 30–37%** — เฉพาะเมื่อแยกค่าแรงไม่ได้ และต้องมีเหตุผลกำกับ

## 2. กฎเหล็ก

- **แยกโหมด**: โหมดราชการห้ามเปิดปัจจัย % อิสระ (กำไร/โอเวอร์เฮด/S.W.C./เงินเผื่อแบบเอกชน); โหมดเอกชนห้ามใช้คำ “ราคากลาง” โดยไม่ติดป้าย “ประมาณการ — ไม่ใช่ราคากลางตามหลักเกณฑ์”
- **ครุภัณฑ์** (`part = "equipment"`) ห้ามเข้าฐาน Factor F; ค่าติดตั้งเป็นบรรทัดแยก + มีเหตุผล/การสืบราคา
- **เงิน**: สตางค์ integer; ห้าม float ในเส้นทางคำนวณ; ปัดเฉพาะจุดที่กำหนดและบันทึก trace
- **ทุกแถวมี PriceEvidence**; แหล่งอื่นนอกจาก TPSO/ตารางค่าแรงต้องมีเหตุผล; ราคา >12 เดือน หรือ `notYetPublished` → flag
- **Ruleset**: โปรเจกต์ pin `rulesetId`; ชุดที่ถูกแทนที่ต้องเตือน; `provenance` ต้องแสดง
- **Disclaimer** ครบทุกจุด; TPSO server-side เท่านั้น
- **เอกสารชุดสมบูรณ์** ต้องมีช่องลงนามผู้จัดทำ/ผู้ตรวจสอบ/ผู้อนุมัติ

## 4. ปร.4 และ contractBase

`Reg2569Report.contractBase` ต้องตรงกับ ปร.4:

- `constructionSat` = `summary.constructionSat` = `calc.afterFactor`
- `equipmentSat` = `summary.equipmentSat` = ผลรวม `p2.rows.totalSat` (ราคา + VAT + ค่าติดตั้ง + VAT)
- `totalSat` = `constructionSat + equipmentSat`
- `totalSat + summary.expenseSat = summary.totalSat`
- `Σ contractBase.lines.baseSat = totalSat`
- งานก่อสร้างกระจายตามสัดส่วน `mat + lab`; เศษเข้ารายการเงินมากที่สุด
- ครุภัณฑ์ใช้ `p2.rows[i].totalSat` — ห้ามใช้ราคาดิบ

**ห้ามใช้ `calc.total` เป็นราคากลางในเอกสารราชการ** — `calc.total` รวมเงินเผื่อจำเป็น/ค่าดำเนินงานของโครงเดิม ใช้ได้เพียง “ยอดเครื่องยนต์เดิม (ไม่ใช่ราคากลาง)” ในเอกสารชุดเก่า

## 5. ปร.3 และแนบท้ายสัญญา

- ปร.3 = ค่าใช้จ่ายพิเศษตามข้อกำหนด; VAT ของปร.3 และการตัดเงินเผื่อจำเป็นยัง **unverified (U1)**
- โครงการที่มี `specialExpenses` → `computePriceReduction` คืน error และไม่สร้าง lines
- แนบท้ายสัญญาใช้ฐาน `contractBase` เท่านั้น; ราคาเสนอต้องต่ำกว่าฐาน
- กระจายอัตราลดเดียวทุกรายการ + เศษเข้ารายการเงินมากที่สุด
- `Σ reducedSat = winItemsSat`; `winningSat = winItemsSat + fixedTotalSat`
- ป้าย “ไม่ใช่ราคากลาง/ไม่ใช่ราคามาตรฐานของกรมบัญชีกลาง” ทั้งหน้าและ xlsx

## 6. Provenance และสถานะปัจจุบัน

| ID | เรื่อง | สถานะ |
|---|---|---|
| U1 | สูตร ปร.3 กับ VAT/การตัดเงินเผื่อของชุด 2569 | **unverified** — ต้องเปิดต้นฉบับ |
| U2 | ตาราง ว 475/477/480/481 จาก mirror | **mirror-unverified** — ยังไม่ตรวจแถวต่อแถวกับราชกิจจานุเบกษา |
| U3 | `ROUNDDOWN(...,-3)` ในแบบฟอร์ม .xls | ยังไม่รองรับ — รอหน่วยงานยืนยัน |
| U4 | ปร.3 กับแนบท้ายสัญญา | บล็อกจนมีแนวทางยืนยัน |
| U5 | พิมพ์จริงกับโครงการหลายหน้า | ยังไม่ทดสอบครบทุกกรณี |

- `official` = ยืนยันต้นฉบับแล้ว; `mirror-unverified` = ต้องมีป้ายเตือน
- ห้ามลบป้ายเพื่อให้ดูผ่าน
- วันมีผลบังคับใช้ต้องมาจาก `effectiveFrom` ที่มีหลักฐาน — ไม่ใช่วันลงหนังสือเวียนโดยอัตโนมัติ

## 7. ปี พ.ศ. และ superseded

- ใช้ `rulesetBeYear(ruleset)` — รับเฉพาะปี ค.ศ. 1900–2100 แล้ว +543
- ปี พ.ศ. ที่ import มา (เช่น 2569-01-01) → `null` (ไม่ใช่ 3112) และติดป้าย unverified
- `rulesetStatus = superseded` → เตือน + พิมพ์บนกระดาษ
- ห้าม hardcode “พ.ศ. 2569” ในโค้ดที่ควร derive
