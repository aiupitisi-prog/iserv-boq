### แก่นสาระ — ผ่อนผัน ๓ กรณี (window ๙ มิ.ย. ๒๕๖๙ จนถึงวันที่ ว 475 มีผลใช้บังคับ)

- **ข้อ ๑ — เงื่อนไขเปิด (๒ กรณีย่อย):** ระหว่างวันที่ ๙ มิถุนายน ๒๕๖๙ จนถึงวันที่หนังสืออ้างถึง ๒ มีผลใช้บังคับ หากหน่วยงานของรัฐคำนวณราคากลางโดยใช้ตารางค่าดำเนินการและค่าเสื่อมราคา**ใหม่** (ตามที่อ้างถึง ๑) และหัวหน้าหน่วยงานของรัฐให้ความเห็นชอบราคากลางงานก่อสร้างดังกล่าวแล้ว — "ให้ดำเนินการดังนี้"
  - **๑.๑** ยังไม่ประกาศเผยแพร่ร่างขอบเขตของงานหรือรายละเอียด**ของพัสดุ** และร่างเอกสารเชิญชวนเพื่อรับฟังความคิดเห็น (กรณีที่ยังไม่ประกาศเผยแพร่เพื่อรับฟังความคิดเห็น) หรือยังไม่ประกาศสอบราคา หรือยังไม่ประกาศประกวดราคา … จัดซื้อจัดจ้างโดยวิธีคัดเลือก หรือยังไม่ทำหนังสือเชิญชวน กำหนดสำหรับการจัดซื้อจัดจ้างแบบเฉพาะเจาะจง → ให้หัวหน้าหน่วยงานมอบหมายให้คณะกรรมการ…พิจารณา(ทบทวน)**ราคากลางใหม่** — tail ข้อความถอดไม่เต็ม (ป้าย unverified ด้านล่าง)
  - **๑.๒** ดำเนินการล่วงเลยไปแล้ว หากหัวหน้าหน่วยงานของรัฐพิจารณาแล้วเห็นว่า ราคากลางนั้นสามารถ(ใช้)สำหรับเปรียบเทียบราคาที่ผู้ยื่น(เสนอ)ด้วยจริง → ให้ดำเนินการตามข้อนั้น(?)ต่อไป — คำเชื่อมกลางถอดไม่เต็ม (ป้าย unverified)
- **ข้อ ๒ — ตารางเดิม (ฉบับ 2560):** ระหว่างวันที่เดียวกัน หากคำนวณราคากลางงานก่อสร้างโดยใช้ตารางค่าดำเนินการและค่าเสื่อมราคาของหลักเกณฑ์การคำนวณราคากลางงานก่อสร้าง ทาง สะพาน และท่อเหลี่ยม ตามประกาศ(คณะกรรมการ?)ราคากลาง เรื่อง หลักเกณฑ์และวิธีการกำหนดราคากลาง(งานก่อสร้าง?) ลงวันที่ **๑๙ ตุลาคม ๒๕๖๐** → **"ให้ถือว่าเป็นการปฏิบัติตาม(ที่?)อ้างถึง ๑"** (ไม่ต้องคำนวณใหม่) — ตัวเลข ๑๙/๒๕๖๐ อ่านชัดจากสแกนโดยตรง · วันที่เปิด window กำกวม รับ "๙ มิถุนายน ๒๕๖๙" ตามบริบท (window เดียวกับข้อ ๑) + kb

**ไม่มีตารางราคา/อัตราใด ๆ ในเอกสารนี้ → ไม่สร้าง ruleset** — เก็บเป็นหลักฐานกำกับเงื่อนไขผ่อนผันของชุด 2569 (เมื่อเครื่องยนต์ตรวจ window เปลี่ยนตาราง ต้องอ้างข้อ ๑/๒ นี้)
