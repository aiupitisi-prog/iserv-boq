# docs/reg-2569/ — หลักเกณฑ์ราคากลางงานก่อสร้าง พ.ศ. 2569 (แฟ้มพยาน)

โปรเจกต์ iserv-boq เตรียมขึ้นเครื่องยนต์คำนวณราคากลางตาม **ประกาศ กระทรวงการคลัง ว 475–481, ลง 26 มิถุนายน 2569**:
ว 475 (ค่าดำเนินการ+ค่าเสื่อมราคา) · ว 476 (ผ่อนผัน) · ว 477 (ค่าขนส่ง) · ว 480 (บัญชีค่าแรงถอดแบบ) · ว 481 (ตาราง Factor F)

## สถานะของแฟ้มนี้

- ไฟล์ PDF ทั้งหมดดึงจาก **Yotathai** (วันที่ 10 พ.ย. 2569) เพราะยังไม่เข้าถึงราชกิจจานุเบกษาตรง ๆ — **ไม่ใช่ทางการ**
- `manifest.md` คือผลตรวจคร่าว (หน้า/ขนาด/sha256/text layer) — ไฟล์ไหน digest เท่านี้ = สำเนาที่นี่เหมือนต้นทางแน่นอน
- ก่อนใช้ค่าในตารางไปคำนวณจริง ต้อง **ยืนยันกับต้นฉบับทางการ** (ราชกิจจานุเบกษา / เล่มราชกิจจานุเบกษาเดือนกันยายน 2569 / สนค.)
  - ว 481 ยืนยันจากตัวไฟล์: หมายเลขทางการ **0433.2/ว 481 ลง 26 มิ.ย. 2569** — ดอกเบี้ยเงินกู้ 6%/ปี, ค่าจ้างล่วงหน้า 0/5/10/15%, ประกันผลงาน 0/5/10%, VAT 7%
  - ว 476 เป็น PDF สแกน — รายละเอียดข้อยกเว้นต้องอ่านจากภาพ/ถอดคู่มือ จึงจะได้ข้อความ
- อัปเดตสถานะจากการตรวจจริง: ตาราง Factor F = **48 ตาราง (4 ประเภทงาน × 12)** ไม่ใช่ 12: อาคาร (หน้า 4–15), งานทาง (17–28), สะพาน+ท่อเหลี่ยม (30–41), ชลประทาน (43–54)
- ตารางย่อยต่อ 1 ประเภทงาน = คอมบิเนชั่น (ค่าจ้างล่วงหน้า 0/5/10/15%) × (ประกันผลงาน 0/5/10%) = 4×3 = 12 ตาราง, แต่ละตารางแถวเป็นช่วงต้นทุน (ล้านบาท) พร้อม 2 ค่า: Factor และ Factor F
