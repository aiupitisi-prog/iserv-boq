## 3. สิ่งที่ทำเสร็จในรอบนี้ (ไฮไลต์)

### 3.1 เครื่องยนต์ต่อชุดตาราง ว 481 (ฝั่ง `lib/calc/`)

`computeGovBOQ` ไม่อ่านแค่ `ruleset.factorF` ตารางเดียวอีกต่อไป:

- เลือกตารางจาก 48 ตารางด้วย `selectFactorFTable(tableSet, cond)` — ประเภทงาน (4 อาคาร/ทาง/ระบบ/ภูมิทัศน์) × ทดรองจ่าย × ประกันผลงาน (มี lerp ช่วงอัตราตามหมายเหตุ 1)
- คอลัมน์ที่ใช้เลือกตามเงื่อนไขสัญญา: ปกติ = Factor F รวม VAT · `noVat` = คอลัมน์ "รวมในรูป Factor" (หมายเหตุ 2) · `rain 1/2` = คอลัมน์ฝนชุก — กรณีตารางไม่มีคอลัมน์ตามเงื่อนไข → บันทึกเหตุผลใน trace แล้วใช้คอลัมน์ปกติแทน (ไม่เดาเงียบ ๆ)
- `noVat` + ฝนชุกพร้อมกัน (ตารางไม่มีคอลัมน์ที่จับคู่ทั้งสอง) → ยกเตือนขึ้นกล่อง warnings เด่น ๆ ไม่ใช่แค่ step note
- golden test กับชุดข้อมูลจริง: ต้นทุน 0.25 ล้านบาท (อาคาร a0-r0) → F 1.3073 → 32,682,500 สตางค์ / แบบ noVat 1.2218 → 30,545,000 สตางค์

> งานส่วนนี้ถูก push ขึ้น remote แล้วก่อนหน้าโดยเซสชันคู่ขนาน (commit `c1f003e`/`c2da9d3`/`d172b12`/`8b0e588` — ซ้ำกัน 8 ก้อน ดู §3.4) — รอบนี้จึงไม่ commit ซ้ำ แค่ตรวจว่าเนื้อหาเหมือนกันจริง

### 3.4 Git — แก้ credential + จัดประวัติที่ซ้ำ + push/deploy

- **Credential:** push ตก 403 เพราะ Git Credential Manager จำบัญชี `danupansitti-glitch` (ไม่มีสิทธิ์เขียน repo) → erase แล้ว store PAT ของ **`aiupitisi-prog`** (ยืนยันตัวตนผ่าน GitHub API `/user` ก่อน) — `git push origin main` ใช้ตรง ๆ ได้แล้ว โดย **ไม่เขียน token ลง `.git/config` หรือไฟล์ใด ๆ** (อยู่ใน GCM + env `GITHUB_PAT` เท่านั้น)
