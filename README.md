# iserv-boq

ระบบจัดทำราคากลาง / BOQ งานก่อสร้าง — เวอร์ชันต้นแบบ (Next.js App Router + TypeScript + Tailwind CSS)

## สิ่งที่มีใน v0.1

- หน้าแรก แนะนำระบบ + ข้อกำหนดการใช้งาน (สำหรับใช้กับงานราชการควรตรวจทานก่อนใช้จริง)
- `จัดทำราคากลาง` (/projects): สร้าง/เปิด/ลบโครงการ BOQ, ตารางแก้ไขรายการ (หมวดงาน, รายการ, หน่วย, ปริมาณ, ราคา/หน่วย), รวมเงินอัตโนมัติรายรายการ/รายหมวด/ทั้งโครงการ, โหลด BOQ ตัวอย่าง 2 ชุด, ส่งออก/นำเข้า JSON, พิมพ์เอกสาร
- `BOQ เอกชน` (/commercial): โครงสร้างกระบวนการคุมต้นทุน → ใบเสนอราคา → วางบิล (ต้นแบบ)
- `คลังราคา` (/prices): ตารางราคาวัสดุ/ค่าแรง/อุปกรณ์ตัวอย่าง ค้นหาและกรองตามประเภทได้
- `บริหารงานก่อสร้าง` (/cm): โครงสร้างแผนงาน/หลักฐานหน้างาน/งานประจำวัน (ต้นแบบ)
- ข้อมูลบันทึกลง localStorage ของผู้ใช้เป็นค่าเริ่มต้น (ไม่มีเซิร์ฟเวอร์) — ส่งออก JSON เพื่อสำรอง/ย้ายเครื่อง

## การติดตั้ง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## การ deploy ผ่าน Vercel

ระงับความจำเป็นให้ npm ทุกอย่าง — แค่ push repo นี้ไป GitHub แล้วกด **Import Project** ใน Vercel
ค่าตั้งต้นของ Vercel จะจับ Next.js อัตโนมัติ ไม่ต้องแก้ build command

## หลักการใช้ตัวเลขราคา

ตัวเลขในระบบเป็นตัวอย่างสมมุติ ก่อนใช้งานจริงให้แทนที่ด้วยราคามาตรฐานของหน่วยงาน เช่น กรมบัญชีกลาง
สพฐ., หรือราคาควบคุมกลางของพื้นที่ — รายละเอียดอยู่ที่หน้า /terms และ /guide
